2. WIE MAN ES NUTZT
--------------------------------------------------------------------------------
  Windows-Start (Core + GUI + Monitor):
      start_destiny_windows.bat

  GUI starten (Streamlit, http://localhost:8501):
      python -m streamlit run src\destiny_gui.py

  Web-Panel / Setup öffnen (Flask, http://127.0.0.1:5000):
      python src\destiny_setup.py

  Chats archivieren:
      - In der GUI Modul „Chat Archivierung“ → Text einfügen → Speichern
      - oder: python src\destiny_archiver.py  (Eingabe, dann Zeile END)
      Zielordner: %USERPROFILE%\destiny_archive

  System prüfen:
      python tools\live_check.py

  Landingpage:
      cd web && npm install && npm run dev
